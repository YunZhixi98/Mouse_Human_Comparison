# Mouse Human Comparison

This repository contains analysis scripts associated with the paper:

### **A Framework for Comparative Analysis of Human and Mouse Cortical Neuron Dendrites in Corresponding Brain Regions**

Zhixi Yun†, Wen Ye†, Nan Ji†, Yujin Wang†, Jing Rong, Tian Li, Yingxin Li, Qi Shen, Ruilong Wang, Hairuo Zhang, Hao Xu, Nan Mo, Binghua Song, Xin Chen, Yi Wang, Yiying Mai, Ming Ding, Song-Lin Ding, Lijuan Liu*, Liwei Zhang*, and Hanchuan Peng*.

***Nature Neuroscience***, 2026

- DOI: [10.1038/s41593-026-02376-z](https://doi.org/10.1038/s41593-026-02376-z)
- URL: https://www.nature.com/articles/s41593-026-02376-z

## Overview

Cross-species comparisons of neuronal morphology can reveal conserved and divergent principles of cortical organization. In this study, we developed a framework for comparing dendritic morphology between mouse and human cortical neurons in anatomically and functionally corresponding brain regions.

The analyses in this repository support the main computational components of the study, including local dendritic morphometry, branch-level feature extraction, cross-species regional comparison, cortical lobe separability analysis, morphology-based clustering, and transcriptomic validation of mouse-human regional correspondence.
